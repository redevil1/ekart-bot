## 🚀 Getting Started

### Prerequisites

Before you begin, ensure you have the following:
- A Telegram account
- Internet connection
- Your Ekart tracking number (AWB/Docket number)

### How to Use the Bot

1. **Search for the Bot**
   - Open Telegram app
   - Search for `@EkartTrackerBot` (or the bot username)
   - Click "Start" to begin

2. **Track Your Package**
   ```
   /track YOUR_TRACKING_NUMBER
   ```
   Replace `YOUR_TRACKING_NUMBER` with your actual Ekart AWB/Docket number

3. **Get Help**
   ```
   /help
   ```
   Display all available commands and usage instructions

4. **Check Status**
   ```
   /status
   ```
   View the status of all your tracked packages

## 🛠️ For Developers

### Installation & Setup

If you want to run your own instance of this bot:

1. **Clone the repository**
   ```bash
   git clone https://github.com/redevil1/ekart-bot.git
   cd ekart-bot
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   pip install -r requirements.txt
   ```

3. **Configure environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your Telegram Bot Token and Ekart API credentials
   ```

4. **Run the bot**
   ```bash
   npm start
   # or
   python bot.py
   ```

### Environment Variables

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
EKART_API_KEY=your_ekart_api_key_here
```
